# Existing generated corpora detected but not imported automatically

During preparation, the following prior generated-data filenames were discoverable in the connected file library:

- `prueba 1 millon.txt`
- `prueba 1 millon - 2.txt`
- `prueba 1 millon CORTO.txt`
- `PRUEBA 100000.txt`

They were **not copied into this public-repository package** because their custody status cannot be established from the filenames alone. Copy a corpus into this directory only after confirming that every mnemonic in it is an intentionally public, never-funded test vector.

This file intentionally does not claim phrase counts or contents beyond what can be established from the detected filenames.
