# LinkedIn Publication Draft

I have published a new archived research-software release of **Architecture of Infinity: Prime Coordinates and BIP-39 Mnemonic Research**.

The project explores BIP-39 mnemonic construction, cryptographic entropy accounting, SHA-256 checksums, deterministic mappings between BIP-39 positions and ordinal prime numbers, absolute-coordinate models, structural filters, Bitcoin wallet derivation tooling, and reproducibility.

One of the most important principles of the project is also one of its limitations: **prime numbers and deterministic transformations are representation mechanisms, not additional cryptographic entropy**.

The repository now includes:

- open Python source code
- automated tests and continuous integration
- technical architecture and data-flow documentation
- reproducibility protocol
- public experimental datasets
- machine-readable metadata
- Zenodo archival DOI
