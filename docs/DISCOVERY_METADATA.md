## Topic strategy

Prefer precise, established technical terms over speculative or promotional terms.

Do not use topics that imply:

- broken Bitcoin cryptography
- seed recovery
- guaranteed uniqueness
- increased BIP-39 entropy from prime numbers

## GitHub metadata checklist

In the repository `About` panel:

- description: use the recommended description above
- website: leave empty unless a canonical project website exists
- topics: use the focused 20-topic set
- releases: keep versioned releases meaningful
- social preview: use the existing project graphic if desired

Machine-readable metadata improves interpretation and discovery, but no file can guarantee that a particular search engine or AI provider will crawl, index, rank, train on, or cite the repository.
