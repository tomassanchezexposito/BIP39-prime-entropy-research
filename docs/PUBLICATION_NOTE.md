# Publication note: full manuscript vs. public-safe manuscript

The supplied Spanish technical manuscript contains exact 12-word reference mnemonic material and enough associated position/prime data to reconstruct it. A public GitHub repository should treat any such mnemonic as permanently exposed.

For that reason this package contains a **public-safe English edition** in which exact reference mnemonic tables and reconstructable sequence data are redacted while the surrounding mathematical discussion, checksum conclusions, software architecture, limitations, and version trace are retained.

A complete unredacted English translation is delivered separately as `Architecture_of_Infinity_EN_FULL_PRIVATE.docx`. Before placing that full file in a public repository, verify that every mnemonic appearing in it is a never-funded test vector and will never be used for custody. If that cannot be established, keep the full edition private.
