# Institutional Outreach

## Banco de España

Use the channel for **consultas sobre innovación financiera de base tecnológica** when the goal is to share or ask about technological innovation applied to financial services.

Position the project as independent experimental research.

Do not frame the contact as:

- a request for investment
- a request for official validation
- a claim that Bitcoin cryptography has been broken
- a legal opinion request

### Suggested subject

`Investigación experimental sobre BIP-39, entropía y representación posicional mediante números primos`

### Suggested message

Dear Innovation team,

I am sharing an independent experimental research project implemented in Python that studies BIP-39 mnemonic construction, cryptographic entropy accounting, deterministic prime-number positional mappings, absolute-coordinate models, structural filters, Bitcoin wallet derivation tooling, and reproducibility.

A central point of the work is that prime-number mappings and deterministic filters are treated explicitly as representations/selection mechanisms and not as additional cryptographic entropy.

The project is publicly reproducible and includes source code, tests, technical documentation, public experimental datasets, and an archived Zenodo software release.

Repository:
https://github.com/tomassanchezexposito/BIP39-prime-entropy-research

Zenodo DOI:
https://doi.org/10.5281/zenodo.22257814

I would appreciate guidance on whether this type of independent technical research is of interest to the innovation channel, or whether another institutional or academic channel would be more appropriate for technical review.

Kind regards,

Tomás Sánchez Exposito

```
## CNMV Portal Fintech

The CNMV Portal Fintech is appropriate when a project raises regulatory questions or when a promoter wishes to present a technology/business model related to securities markets.

For this repository, use it only if there is a genuine securities-market / fintech relevance.

### Suggested subject

`Proyecto experimental de investigación sobre BIP-39, Bitcoin y reproducibilidad`

### Suggested message

Dear CNMV Fintech Innovation team,

I am sharing an independent experimental software-research project related to BIP-39 mnemonic construction, cryptographic entropy accounting, Bitcoin wallet derivation, deterministic prime-number positional representations, and reproducibility.

The project is not presented as a financial product or custody service. Its current purpose is technical research, documentation, reproducibility, and public discussion.

Repository:
https://github.com/tomassanchezexposito/BIP39-prime-entropy-research

Zenodo DOI:
https://doi.org/10.5281/zenodo.22257814

I would be grateful for guidance on whether this research is relevant to the Portal Fintech's scope or whether another channel would be more appropriate.

Kind regards,

Tomás Sánchez Exposito
```

## Institutional communication rule

Never imply that receiving a response from a regulator constitutes:

- certification
- approval
- authorization
- endorsement
- validation of security claims
