# External Dissemination Strategy

## Objective

Increase legitimate visibility, citation, technical review, and external discussion of the project without overstating its claims.

The dissemination strategy should prioritize:

1. persistent scholarly discovery
2. technically relevant communities
3. institutional innovation channels
4. reproducible-research audiences
5. Python/open-source communities
6. selected social/professional channels

## Canonical links

Repository:

https://github.com/tomassanchezexposito/BIP39-prime-entropy-research

Archived software release:

https://doi.org/10.5281/zenodo.22257814

## Core positioning

Use this formulation consistently:

> Independent experimental research on BIP-39 entropy accounting, deterministic prime-number positional mappings, absolute-coordinate models, structural filters, Bitcoin wallet derivation tooling, reproducibility, and machine-readable research datasets.

Always preserve these interpretation constraints:

- prime-number mappings do not add cryptographic entropy
- absolute coordinates do not add cryptographic entropy
- deterministic filters do not create randomness
- SQLite duplicate history is local, not global
- public mnemonic datasets are experimental public data, not wallet secrets

## Priority channels

### Tier 1 — scholarly infrastructure

- Zenodo record
- Zenodo Communities
- OpenAIRE EXPLORE
- ORCID, if the author has one
- future manuscript/preprint DOI

### Tier 2 — research/technical communities

- reproducible research
- research software engineering
- Python scientific/open-source communities
- number theory / computational mathematics audiences
- Bitcoin protocol and wallet engineering communities where technically relevant

### Tier 3 — institutional innovation channels

- Banco de España innovation facilitators
- CNMV Portal Fintech
- university research groups
- cybersecurity / cryptography / distributed-systems groups

Institutional contact should be framed as sharing independent research and requesting orientation or technical feedback, not as claiming regulatory endorsement.

### Tier 4 — professional visibility

- LinkedIn technical publication
- personal/project website
- GitHub discussions/issues
- selected technical newsletters or forums

## Sequence

Recommended order:

```text
Zenodo DOI
→ Zenodo Communities
→ OpenAIRE discovery check
→ institutional outreach
→ academic/research-group outreach
→ technical communities
→ LinkedIn/professional dissemination
→ future manuscript/preprint
```

## Success metrics

Track:

- GitHub stars/forks/watchers
- GitHub traffic
- DOI views/downloads
- Zenodo community acceptance
- external citations
- backlinks
- issues/discussions opened by third parties
- academic/institutional responses
- replication reports

Do not optimize for raw impressions alone. Technical review and independent reproducibility are higher-value outcomes.
