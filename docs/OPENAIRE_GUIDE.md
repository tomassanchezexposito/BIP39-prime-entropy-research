# OpenAIRE Discovery Guide

## Objective

Use OpenAIRE as an external scholarly discovery layer for the Zenodo software record.

## Expected path

Zenodo is an OpenAIRE-compatible catch-all repository and Zenodo research objects can be indexed and made discoverable through OpenAIRE EXPLORE.

## What to verify

Search OpenAIRE EXPLORE for:

- DOI: `10.5281/zenodo.22257814`
- exact title
- author name

If the record is not visible immediately, allow indexing time before concluding that it is missing.

## Metadata consistency

When visible, verify:

- title
- creator
- software resource type
- DOI
- publication date
- repository relation
- keywords
- open-access status

## Future linking

If later there are separate research objects for:

- software
- manuscript
- datasets

link them using persistent identifiers so the research graph shows the relationships among them.

Current software DOI:

`10.5281/zenodo.22257814`
