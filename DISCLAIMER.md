### Why the initial position matters

For the 12-word branch, the implementation fixes the first 11 bits from the selected local position and generates the remaining 117 bits with the operating-system-backed CSPRNG exposed by Python `secrets`. Across all 2,048 possible initial positions, the full BIP-39-compatible encoding space is `2^128`; **for one known fixed initial position, the random continuation generated by this implementation is `2^117`**.

A predictable human-selected initial position therefore leaks 11 bits of the entropy field relative to choosing all 128 entropy bits independently. The safer experimental variant is to select that position with a CSPRNG rather than by a predictable rule.

### What the prime architecture does *not* do

- The prime assigned to a word index is a deterministic label; it adds no random bits.
- An absolute position that grows without bound does not create infinite entropy.
- A BIP-39 checksum detects some invalid encodings; it does not add unpredictability.
- Rejecting visually linear patterns changes the accepted distribution; it is not evidence that rejected strings were non-random.
- SQLite duplicate hashes prevent re-emission only within the local history available to that installation; they cannot guarantee global uniqueness across independent wallets.

### BIP-39 passphrase: important, but not permission to expose a mnemonic

BIP-39 allows a passphrase. The mnemonic is used as the PBKDF2 password and `"mnemonic" + passphrase` as the salt; every passphrase produces a valid seed. This is useful as an additional secret, but it does **not** make it sound practice to publish a real wallet mnemonic. If the mnemonic is public, the passphrase becomes the remaining secret and weak or reused passphrases become an obvious target.

For private experiments:

- use a high-entropy, unique passphrase generated/stored securely;
- keep the mnemonic and passphrase in separate secure locations;
- do not confuse a wallet application's login password with the BIP-39 passphrase;
- test recovery before relying on any backup;
- understand that a typo or lost passphrase derives a different wallet and cannot be recovered from the mnemonic alone.
